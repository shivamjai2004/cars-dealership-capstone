# Cars Dealership Capstone Project

Welcome to the Cars Dealership web application project! This application displays dealership branches, allows users to view and submit reviews, performs sentiment analysis, and features a robust microservices architecture deployed via Docker, Kubernetes, and IBM Cloud Code Engine.

## Tech Stack
- **Frontend:** React, HTML5, CSS3, Bootstrap
- **Backend:** Django, Node.js, Python Flask (Sentiment Analyzer)
- **Databases:** MongoDB, SQLite
- **DevOps & CI/CD:** Docker, Kubernetes, GitHub Actions, IBM Cloud Code Engine
